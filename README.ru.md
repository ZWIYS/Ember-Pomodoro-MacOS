# Ember

Минималистичный помодоро-таймер, который живёт в меню-баре macOS.

[English version](README.md)

> **Статус:** ранняя разработка (v0.1). Основной таймер и интерфейс готовы.

## Обзор

Ember висит в меню-баре и показывает оставшееся время рядом с маленькой точкой статуса:

- оранжевая точка: рабочая сессия
- жёлтая точка: перерыв

Клик по элементу в меню-баре открывает полупрозрачное окно.

### Экран настройки

- **Session**: длительность сессии в минутах
- **Break**: длительность короткого перерыва в минутах
- **Cycle**: количество коротких перерывов до длинного
- **Long break +N**: на сколько минут длинный перерыв длиннее короткого (длинный = короткий + N)
- **Start**

### Экран работы таймера

- Заполняющееся оранжевое кольцо с обратным отсчётом внутри
- Кнопки **Pause** и **Stop**
- **+5 min**: продлить текущую сессию, не останавливая её

Фазы переключаются автоматически: сессия, перерыв, сессия и так далее. В конце фазы играет мягкий звук, а цифры в меню-баре меняют цвет.

## Дизайн

- Светлая и тёмная темы
- Оранжевый акцент на тёмно-сером
- Полупрозрачный фон с блюром
- Интерфейс приложения только на английском

## Технологии

- Swift, SwiftUI-окно внутри `NSStatusItem` (чтобы можно было красить текст в меню-баре)
- Swift Package Manager, проект Xcode не нужен
- macOS 13 и новее

## Сборка

Нужен Swift (Xcode или Command Line Tools).

```bash
git clone https://github.com/ZWIYS/Ember-Pomodoro-MacOS.git
cd Ember-Pomodoro-MacOS
./scripts/build-app.sh
open build/Ember.app
```

Запуск без сборки пакета: `swift run`.
